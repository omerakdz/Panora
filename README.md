# PANORA - Moderne Ramenwasdienst Platform

Een modern en gebruiksvriendelijk boekingsplatform voor professionele ramenwasdiensten in Gent en omgeving. PANORA biedt een transparante, digitale ervaring met realtime prijsberekening en directe online boeking.

## ✨ Features

- **Interactieve Prijscalculator** - Stap-voor-stap prijsberekening op basis van woningtype, aantal ramen en extra's
- **Google Calendar Integratie** - Realtime beschikbaarheid en automatische agenda-synchronisatie
- **Online Boekingssysteem** - Direct online afspraken maken met bevestiging per email
- **Review Systeem** - Geautomatiseerde review-aanvragen via email na voltooide services
- **Contact Formulier** - Direct contact via website met email notificaties
- **Responsive Design** - Volledig geoptimaliseerd voor desktop, tablet en mobiel
- **Moderne UI** - Clean, professioneel design met Tailwind CSS

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Taal:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** Radix UI, Shadcn/ui
- **Email:** React Email, Nodemailer, Resend
- **Integraties:** Google Calendar API, Google Reviews API
- **Datum Handling:** date-fns, react-day-picker
